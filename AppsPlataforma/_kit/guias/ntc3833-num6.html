¿Para qué sirve?

Evalúa en tiempo real la localización del extremo terminal del ducto de evacuación según el tipo de artefacto (NTC 3833, Numeral 6).

Cómo usarlo

  1. Seleccione el tipo de artefacto (B.1, B.2 inducido, B.2 forzado o C). Para tipo C ingrese la potencia nominal.
  2. Indique si el ducto se comparte con combustibles sólidos o líquidos.
  3. Ingrese las distancias medidas en metros. El resultado se actualiza al escribir.
  4. Si faltan mediciones obligatorias el resultado indica Evaluación incompleta.
  5. Diligencie proyecto e inspector y genere el Informe PDF.
